## 1. Overview & Objectives

The **Admin FOS Usage Ledger** page provides granular auditability into Fastly Object Storage (FOS) operations. It breaks down every Class A (LIST/PUT/POST) and Class B (GET/HEAD) call by caller component (API route vs individual cron job), tracking byte sizes, response codes, and estimated cost allocations.

### Key Tenets:
- **Zero Dark Cloud Ops:** Every S3/FOS API call executed by any thread or worker is logged with component attribution.
- **Cost Isolation:** Attributes cloud storage costs accurately between ingest, compaction, optimization, and serving tiers.
- **Strict RBAC:** Accessible **exclusively** to Admin (`read_write`) users. Analysts receive HTTP 403.

---

## 2. Routes & URL Schema

- **Primary Route:** `/admin/usage-log`
- **Supported Query Parameters:**
  - `service`: Fastly Service ID.
  - `component`: Filter by caller (`sync`, `commit`, `compact`, `api`, `optimize`).
