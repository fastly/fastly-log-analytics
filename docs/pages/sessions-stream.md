# Page Specification: Stream Session Detail & QoE Inspector (`/sessions/stream`)

> [!NOTE] **Live-certified on `release/v3.0.0-beta3`**
> This specification defines the verified contract, architecture behaviors, role permissions, and test suites for `/sessions/stream`. Validated across Local Standard, Remote Standard GCE, and High-Scale Elevation deployments with full query attribution and zero layout shifts.

---

## 1. Overview & Objectives

The **Stream Session Detail & QoE Inspector** provides deep video Quality of Experience (QoE) analytics for media sessions carrying Common Media Client Data (CMCD) v1/v2 telemetry. Navigated via a cryptographically sealed `session_token` from the User Sessions Explorer (`/sessions`), it decomposes video playback sessions into playback duration, bitrate tiers, buffer health, rebuffering starvation events, throughput vs RTT correlations, and media object type breakdowns.

### Key Tenets:
- **CMCD Quality Telemetry:** Extracts and visualizes video bitrates (`cmcd_br`), buffer starvation flags (`cmcd_bs`), buffer length (`cmcd_bl`), measured throughput (`cmcd_mtp`), and object types (`cmcd_ot`).
- **Interactive Timeline:** Tracks rendition switches, buffer levels, and network throughput across the lifespan of the video playback session.
- **Buffer Starvation Audit:** Detects playback stalls and buffer starvation incidents with millisecond precision.
- **Fail-Safe Token Handling:** Displays an informative guidance alert if navigated to without a `token` parameter, pointing operators back to the `/sessions` explorer.

## 2. Routes & URL Schema

- **Primary Route:** `/sessions/stream`
- **Supported Query Parameters:**
  - `service`: Fastly Service ID.
  - `token`: Cryptographically sealed opaque session token (`session_token`), generated by `/api/sessions`.

## 3. Role & Permission Matrix

| Role | Access Level | Data Redaction & Capabilities |
|---|---|---|
| **Admin (`read_write`)** | Full Access | Full QoE metrics, unmasked client IPs, full request attributes, and media segment URLs. |
| **Analyst (Remote Share)** | Read-Only Access | Full QoE graphs, buffer distributions, and segment tables viewable; client IPs masked (if enabled). Allowed via unsealed `session_token` on `POST /api/sessions/detail`. |

## 4. Architecture Execution Matrix

| Component / Subsystem | Standard Mode (`DEPLOYMENT_MODE=standard`) | High-Scale Mode (`DEPLOYMENT_MODE=high_scale`) |
|---|---|---|
| **Data Plane** | Reads DuckDB session request logs via `execute_with_stale_view_retry` on `POST /api/sessions/detail`. | Queries ClickHouse `request_facts` partitioned table for the unsealed session time extent. |
| **CMCD Aggregation** | Client-side aggregation engine (`useStreamAggregates`) computes timeline, starvation events, bitrate histograms, and buffer distributions. | Same client-side aggregation engine running on returned ClickHouse records. |

## 5. Backend APIs & Telemetry Attribution

### Endpoints Hit:
1. `POST /api/sessions/detail`:
   - Body: `SessionDetailRequest` (`session_token`).
   - Returns: `SessionDetailResponse` (`columns`, `data` rows of individual media requests).
   - Tagged with structured telemetry span `process_context_scope("sessions:detail")`.

### Telemetry Attribution:
- Every query carries `X-Page-Load-ID`.
- Database statements recorded in `telemetry_queries` and audited for efficiency.

- **In-Place Skeletons:** Renders skeleton blocks during initial fetch.
- **Container Testids:** Decorated with `data-testid="stream-detail-client"`.

## 7. Interactive Workflows & Edge Cases

- **Missing Token State:** When navigated without `?token=...`, renders an informative `Alert` with link back to `/sessions`.
- **Non-Video Streaming Session:** When a session carries CMCD telemetry but lacks media segment requests (e.g., manifest-only sessions), displays a clear alert stating that video-specific metrics require media segments.
- **Partial Session Truncation:** If a session exceeds 500 requests, displays an alert noting that analysis covers a partial session (first 500 requests).
- **Navigation Breadcrumb:** Top header includes a direct back button returning to the main `/sessions` explorer.
